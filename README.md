# GSTR-2B RECONCILIATION

Responsive, installable PWA for Harsh Patel Accounting. It compares GSTR-2B and purchase-register CSV/JSON files locally in the browser.

## Use
Open `index.html` in a static host. Upload both files or use the sample data. Results can be downloaded as CSV/JSON or printed to PDF.

No Play Store ID or server is required for the web/PWA version. Deploy the repository with GitHub Pages, Netlify, or Vercel over HTTPS for reliable PWA installation.
